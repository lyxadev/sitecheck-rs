# Contributing

Thanks for your interest in sitecheck-rs.

1. Fork the repository and create a branch.
2. Run `cargo fmt`, `cargo clippy -- -D warnings` and `cargo test` before opening a pull request.
3. Keep changes focused, add unit tests for new checks, and do not add network access to the tests.
4. Describe the problem and the change clearly in your pull request.

By contributing you agree that your work is released under the MIT license.
